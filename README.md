# AIML Experiment 05 - SVM Spam Detection

## Aim
To detect spam mails using Support Vector Machine (SVM).

## Algorithm Used
- Support Vector Machine
- TF-IDF Vectorization

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Description
This experiment uses text data to classify emails as Spam or Not Spam.
TF-IDF is used to convert text into numerical features and an SVM classifier
is trained to detect spam messages.

## How to Run

```bash
python svm_spam.py
